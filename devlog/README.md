# Devlog — Git Shelters

Public devlog of building Git Shelters. Weekly cadence, Fridays.

## Structure

- `drafts/` — post outlines in priority order. Each file has a title, thesis, source material in the GDD, suggested structure, and Bluesky thread hooks.
- `published/` — published posts (to be created when the first one ships).

## Where posts live

- **Canonical** (long post, 800–1500 words): pick one platform and stick with it — own site, Substack, or dev.to.
- **Short thread** on Bluesky (and/or Twitter): links to the long post + 2–3 visual hooks.
- **Selective LinkedIn cross-post**: only strategy/product posts, not pure technical ones. Matters for the US job hunt.

## Tone principles

- Technical but human. Recruiters read this. So do other devs.
- Show the work, show the reasoning, show reversible and irreversible decisions.
- Don't hide mistakes. A public pivot is portfolio material.
